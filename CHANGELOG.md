# Unreleased — local workflow, resource and first-use fixes

- Default task/native execution allowances are 3000 seconds; cumulative branch
  budgets and validated opt-in solved-level continuation keep retries bounded.
- Expose CAD revision region diagnostics, physics mesh policies, assembly resource
  estimates, measured phase observations and structured Agent recovery.
- Viewer loads selected fields on demand, handles disconnected responses and
  cancels deselected requests. File/expanded-NPZ guards are consistently 256 MiB.
- Add explicit cache inventory, verified archive and fresh restore without
  automatic deletion; expose the actual runtime/Skill identity in doctor.
- These are local maintenance updates, not a newly qualified public release.

- Reuse compatible runtimes and configured solvers; default setup installs only
  runtime dependencies. Windows `-Locked` retains maintainer reproducibility.
- Viewer opens without an implicit reference solve. First-use examples and full
  test/release suites are optional; direct Python invocation avoids shell activation.
- License audits tolerate line-ending conversion while rejecting content changes.

- Ordinary installation no longer requires release/development receipts or repeated
  source/copy SHA-256 comparisons. Release auditing is explicit (`--verify-release`).
  `--development` remains accepted without a receipt; installation does not claim
  release qualification. Runtime, solver files and user outputs remain untouched.
- Include both `Open_Viewer.cmd` and the Chinese-named Viewer launcher when present.
  Required files, path containment, backups and solver-download integrity remain.

  feedback share one workspace. Default Viewer labels identify the revision
  workspace and check; explicit labels remain supported.

  join the existing scoped structural/contact paths. Method limits remain explicit.

  document useful passes, failures and unresolved results without product promotion.

  substantive examples, current audit closure and license/privacy checks.

  threshold relaxation or upload. Strict local thermal-flux accuracy remains
  outside the qualified claim; example local-stress failures remain visible.
