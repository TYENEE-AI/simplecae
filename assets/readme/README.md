# README illustrations

- `capabilities-concept.png`: AI-generated editorial illustration commissioned for
  SimpleCAE, 2026-10-21. The bracket, heat bridge and robot arm illustrate capability
  categories. Colors, arrows and deflection outlines are conceptual, not solver data.
- `architecture-en.svg` / `architecture-zh.svg`: authored vector diagrams of the
  Agent, optional CAD skills, SimpleCAE toolkit and Viewer/file feedback loop.
- `decision-loop-en.svg` / `decision-loop-zh.svg`: authored decision diagrams.
  An independently established failure remains actionable even if another check
  is unresolved. Passing one stated model does not grant product acceptance.

The root README separately uses the real CAD preview and recorded numerical
example from `examples/showcase/thermal-bridge`. The preview is not a temperature
contour. See that example's inputs and reproduction instructions for evidence.

No third-party repository images or logos were copied. These assets are supplied
with the project's license; they are documentation, not engineering validation.
