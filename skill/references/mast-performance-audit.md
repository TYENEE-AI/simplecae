# 传感器立柱：接触性能与根部应力审计（2026-10-20）

本轮修复本地开发源码，不更新全局安装，不上传发布。前一轮
[网格/接触审计](mast-repair-audit.md) 的失败记录仍保留。
**第三档接触超时已解决；根部局部强度收敛仍未解决，但原因已有受控对照证据。**

## 1. 原工况是否改变

复测直接读取上一轮 `focused-final/contact.case.json`，没有重写工况：
5 N 横向载荷、50 N 轴向载荷、重力、材料、两根各 300 N 的预紧连接、
接触刚度/摩擦、约束、所有服务与锁定阶段均保留。全局网格仍为
6 / 4.5 / 3.3 mm，上一轮的曲面局部细化保持不变，单元上限 20,000。
位移限值 0.3 mm、强度安全系数 2、应力收敛 10%、位移收敛 5%、
平衡误差 5e-4、负接触压力拒绝阈值 -1e-7 MPa 等原判据均未改变。
本轮没有换网格去寻找一个“绿色”解，没有删载荷、节点、接触积分点或热点。

最终三档复测继续使用原**单次 120 秒、总计 240 秒**上限。
此前已验证的预紧/服务整步控制以及恒载锁定阶段沿用上一轮，不是本轮再放大加载步。

## 2. 性能瓶颈与同输入对照

本机为 i9-12900K（16 核/24 线程），可见内存约 128 GiB，
诊断时可用约 99 GiB。单线程进程采样工作集约 237 MiB。
这不支持“内存不足导致本次超时”的解释，亦不能据此推断其他模型的内存需求。

第三档 9,641 个 C3D10 单元、18,476 个物理节点，原生方程数约 50,727；
接触叠加最多生成 91,699 个弹簧，完成一次全载荷历史需要 23 次矩阵分解。
原来的 120 秒发生在服务阶段，残差仍在下降。

对**字节完全相同**的 `job.inp` 做三个独立有限时长诊断：

| 求解配置 | 完整原生历史耗时 |
|---|---:|
| 原 `ccx.exe`，单线程 | 137.98 s |
| `ccx_MT.exe`，只将方程求解设为 2 线程，其余 1 线程 | 108.94 s |
| `ccx_MT.exe`，方程/组装/结果均请求 2 线程 | 92.23 s |

单独并行方程求解已明显缩短时间，组装/结果计算也有收益，支持
“反复稀疏分解及其周边接触迭代成本是主要性能问题”的解释。
这是同机、同输入的实测，不是精确 CPU 火焰图，也不是通用加速比保证。
stdout 原生缓冲使到达时间不能可靠拆分每个函数耗时，因此没有伪造耗时占比。
没有安装新的求解器、依赖、GPU 框架或复制开源实现；使用原下载发行包已有的 MT 构建。

三个阶段的全部节点/积分点位移、反力、应力、应变做逐项覆盖和数值对照，
结果见 `field-replay-comparison.json`。原生接触场仍独立检查，不靠对照相似性授予通过。
并行构建/线程数显式记录；默认仍串行，其他构建或线程数不能自动继承本机验证。

## 3. 完整原工况复测

双线程完整三档：2,845 / 4,640 / 9,641 单元，原生求解约
19.98 / 36.66 / 91.64 秒，总 worker 192.38 秒。所有阶段到达完整端点。

| 指标 | 粗网格 | 中网格 | 细网格 |
|---|---:|---:|---:|
| 最大位移 mm | 0.100393 | 0.100607 | 0.101434 |
| 装配全局峰值 von Mises MPa | 7.16176 | 7.38651 | 7.58168 |

预紧、锁定、服务三个阶段的原有全局强度/刚度、接触、连接和平衡检查均通过。
这里的结论是**这一三档接触模型的检查通过**，不是根部奇异应力已解决。
全局最大值主要由其他区域控制，不能覆盖已识别的局部敏感性；本任务仍保留
独立根部检查的未解决结论，不能把这个装配记录当成整个设计已完成验证。

## 4. 根部是坏网格还是尖角

用原来的理想固定立柱静力子问题作受控局部网格研究：
同一 CAD、材料、载荷、支承、全局 3.3 mm 网格及曲面细化，仅对根部相邻
顶面设置逐级局部尺寸，过渡距离保持 2 mm。没有重复无关的特征值求解。
这与完整接触装配是不同支承范围，不能混用其应力数值。

| 根部目标尺寸 mm | 单元数 | 完整峰值 MPa | 最大位移 mm | 热点 SICN |
|---|---:|---:|---:|---:|
| 2.145 | 5,912 | 7.62889 | 0.0994693 | 0.856 |
| 1.485 | 7,169 | 8.46542 | 0.0995839 | 0.906 |
| 0.990 | 9,811 | 10.47570 | 0.0997209 | 0.821 |

所有网格通过原生质量门槛；热点自适应 Jacobian 为正、形状良好。
峰值仍位于立柱与底脚的无圆角内凹过渡附近，随局部细化上升；
最后一次应力变化约 19.2%，仍未满足原 10% 判据。
位移仅有很小变化，固定物理坐标 `(-7,2,12)` mm 的诊断应力约
3.847 / 3.864 / 3.881 MPa，另外两个固定偏移点也较稳定。
这些偏移应力由同一 C3D10 位移梯度和原各向同性材料计算，仅用于定位诊断，
没有用于替换任何验收峰值。

新版亦重新完整运行原来的三档立柱静力/屈曲检查（`root-original`）：
结果仍为 `indeterminate`，根部应力约 5.516 / 6.108 / 6.871 MPa，
最后一次相对变化仍约 11.1%。新反馈不会因装配检查通过或位移稳定而清除这项未解决记录。

**证据高度支持理想尖角引起的局部应力奇异性，明显不支持热点畸变单元是主因。**
有限次网格研究不是解析奇异性证明；也没有在这里验证实际制造圆角。
可行下一步是提供真实根部过渡半径，或明确提出带圆角的 CAD 新版本，再保留原载荷
复算完整安装模型。不能通过继续全局加密、删除峰值、改百分位应力或扩大容差解决。
本轮没有擅自修改原始几何。

## 5. SimpleCAE 的通用修复

- `task run` / `design-check` 默认 `--timeout auto`：共享明确的总预算。
  用户给数字时仍严格执行单次上限；总截止时间始终保留。
- `doctor` / review 输出本机资源快照；原生求解输出实际耗时、方程数、
  接触弹簧与分解次数、观察到的 SPOOLES 线程数。
- 每档结构网格给出基于已完成网格的粗略耗时预测，供 Agent 安排预算，
  预测不参与接受、截断或修改判据。
- 显式求解器构建可进入多线程验证路径；不再把所有多线程请求一律挡在外面。
  默认串行不变，原生场判据继续逐次执行；环境中的外来 stiffness 线程变量
  不得覆盖本次明确的线程请求。
- 应力不收敛反馈返回原峰值、位置、元素尺寸/质量和位移趋势，
  原因保持 `unresolved`，给 CAD Agent 可验证的局部细化/圆角调查方向。

以上均没有传感器、几何坐标、材料名称、载荷数值或特定可执行文件哈希的运行时分支。
算例特定参数只在 `validation/mast_*.py` 与证据目录中。
计算精度与验收判据分开：允许合理分配网格/步骤/线程/时间，
不允许降低用户要求来适配硬件。详见 [通用资源流程](execution-resources.md)。
