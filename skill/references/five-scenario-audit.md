# dev12 联合使用审计

2026-10-20，本地开发验证。先将全局安装同步到经过热流复核的 dev11，
再用 SimpleCADAPI 2.2.4 与全局 SimpleCAE 执行五种模拟用户任务，
合计七个 CAD 设计版本。输入/网格修复不冒充新的结构改进。
这些是实际生成的 STEP 装配和真实后端任务，不是五个已经通过验收的产品。

## 使用结果与停止依据

| 场景 | 检查和实际结果 | CAD/Agent 决策 |
|---|---|---|
| 新手相机悬臂 | 4mm PETG 等效梁的网格/力平衡通过，但原始最大位移7.213mm超出小响应范围；10mm版本最大位移0.478mm，满足0.5mm限值及原强度判据 | 独立梁估算支持加厚假设，再重新求解；原版不参与有利排名，打印及夹持另测 |
| 工程师传感器立柱 | 带孔/轴向螺栓端口的底座、立柱、传感器包络；预紧锁定/平面摩擦、屈曲和无预应力模态均实际调用。原网格二次单元质量拒绝；一次细化后接触超过120s求解预算，屈曲/模态超过原单元预算 | 不增加虚构导向、不降低门禁、不删曲面或热点；达到本轮预算后停止，不能判定结构弱或安装合格 |
| 学生控制板导热支座 | 5W、20°C理想冷端、40°C上限；2mm桥最高49.94012°C，4mm桥34.97006°C。热阻估计与实体温度一致；另执行声明10J/K热容的集总升温 | 只改导热截面；实体温度可同条件比较。网络热阻变化仍不被偷偷作为相同网络合同排名；局部热流精度与实际散热不获认证 |
| 集成商双连杆检验臂 | CAD惯性、三组运动状态、两个姿态的连杆FEM与关节柔度；驱动需求通过，四个连杆/姿态结果各自通过，累计传递转角门禁失败 | 保留整机证据不足；提示检查关节保持状态、累计转角与模型范围，不盲目加厚。原始末端位移不是合格精度预测 |
| 创客可重复卡扣 | 带根部圆角、按压垫、机械止挡的四体模型；静力小响应失败且峰值应力未收敛；疲劳/蠕变缺少真实曲线 | 停止寿命声明和材料数据缺失引起的CAD循环；进一步工作需实际材料数据、有效应力历史及止挡接触模型 |

CAD 定位约束只说明声明位置可解。外部几何记录的范围限定为有效实体、
尺寸和指定接口；不把它扩展为工具可达、制造、装配强度或产品验收。
夹座头部间隙和卡扣圆角空间均在正式输入冻结前修正，初始失败记录保留。
机器人关节和螺栓采用明确的等效模型，不声称已有完整可制造驱动/紧固件设计。

## 发现、修复与审查

- **P1：未合格位移仍给定量加厚建议。** 原本结果正确标为证据不足，
  但 `design_guidance` 仍输出刚度倍率和立方根加厚关系。现只有相应判据
  有效且确认为失败时才给定量建议；原始值、位置、峰值和失败记录仍在。
  强度未收敛不会抹去独立合格的刚度失败。
- **P2：简报混淆网格问题与模型范围问题。** 新增对现有小响应、
  整链转角/翘曲门禁的简明解释及 `review_model_validity` 下一步，
  同步到 Viewer。没有改变转角、小响应、翘曲或网格阈值。
- **P2：同一未变任务可无理由无限重算。** 重复计算在启动 worker 前拒绝；
  明确执行环境修复可填写 `retry_reason`，并保留历史。由显式深度拒绝转到
  detailed 仍可直接调用。没有增加队列、自动求解策略或后台服务。
- **P2：安装状态和旧文档混用。** 清理“全局仍为dev10”等过时断言，
  用实际CLI版本确定安装状态；历史验证记录仍作为历史记录保留。

审查覆盖新分支、五场景回放、源文件差异、判据与原失败记录。
产品名、尺寸和材料常数仅出现在场景输入/生成脚本，未进入通用运行时代码。
本轮未修改求解方程、网格接受阈值、力平衡、热量平衡、材料限值、
热流严指标或产品通过标志。没有裁剪、百分位过滤热点。
没有把单体/局部通过提升为整机或产品通过。

首轮全回归暴露新增诊断未处理正常的空机器人测点评估，已修复。
另一个旧测试手写了彼此矛盾的判定，改为从一致场数据重新计算原判据，
没有修改限值来让测试通过。

最终 Python 全回归733项通过；Viewer补充显示后相关47项通过，JS语法检查通过；
五场景原始结果回放14项通过。浏览器实际核对温度迭代、失败历史、
小响应诊断和物理待办。完整原始 dev11 结果保留，dev12 回放不改写求解结果。
局部热流严指标此前未达标的原记录继续保留，不因此获得热流资格。

## 保留边界与后续优先级

通用调用已覆盖这些决策类型，但复杂曲孔接触仍可能昂贵、网格失败。
这一轮没有解决所有接触性能问题，也没有验证真实材料、摩擦、温升或寿命。
下一步宜针对实际需求优化可诊断的网格/计算成本；不应无条件提高预算，
也不应再加入一套自动调参框架。

全局环境先按请求更新为dev11；dev12为本地源码迭代。全新系统安装、
跨平台、公开归档及物理产品认证不在本轮新增资格内。未上传发布。
测试夹具缓存可删除，源码、CAD、关键完整场、失败、输入、日志与哈希保留。
