# 使用 SimpleCAE 做初步设计

首次试用先按 [README](../README.md) 建立环境，再运行 `quickstart --out 新目录`。无需准备自己的 CAD；[三种结果和一次几何迭代](../examples/preview/USE.md)帮助区分通过、失败和证据不足。遇到障碍可复制[反馈模板](../assets/feedback-template.md)。

把它用于“这个设计在这些条件下是否合适”，先看受力、变形、失稳或驱动力的瓶颈，再修改模型。几何文件通常缺少材料、真实固定方式和使用载荷，不能单凭外形得到实际承重。

也可以只告诉Agent“怎么用、希望怎样、什么情况会不好用”。Agent先做[使用检查计划](use-driven-checks.md)，选择几何／运动、简单计算、有限元或实物检查。用户不用自己决定在哪里加力、固定什么面。有限元只针对会影响本次决定的部件和受力路径；未检查的强度／安装／精度要求仍保留，不能被其他零件通过覆盖。

从工具目录运行 `prepare 模型路径 --out 新目录`，打开生成的 `guide.html`。STL/OBJ 要加 `--units mm` 或实际单位；GLB 场景需要明确的 occurrence。向导会显示实际尺寸、面编号和位置，再收集材料来源、固定面、加载面、总力、允许变形与安全系数。挂物质量可以换算成向下重量；零件自身重量是另一个固定作用。空缺信息会提示补充，未勾选的条件保持未确认。

向导适合均匀零件的简单静力输入和 URDF 指定姿态。打印方向、复合材料、多实体连接及复杂载荷用对应模板，由 agent 帮助整理，不能把整面固定自动解释成几颗螺钉的安装。局部加载区需先在 CAD 中分区。多实体场景先做 `inspect --all-bodies`，不要合并成一个实心块。

固定方式现在可以分成多个明确区域：座面只限制法向，导轨保留滑动方向，再由真实限位或驱动限制它。表单会写出实际XYZ位移分量，并提示尚未约束的平移/转动。销位两方向近似可能同时锁住转动，不等于有间隙的自由销接。若诊断仍缺约束，应补真实安装信息，不能为了计算成功自动全固定。

把整理好的 JSON 交给 agent，执行 `check case.json` 后用 `analyze case.json --out 新分析目录`。打开 `report.html`：先看结论和未确认条件，再看强度/变形利用率，最后定位问题区域。100% 表示输入的允许值，超过它意味着该项不满足要求。蓝色和红色显示同次分析的较低/较高数值，不能单凭颜色判断安全。变形图可放大；屈曲动画仅展示理想失稳形状，幅值任意。

机器人报告可切换声明姿态，显示实际 URDF 外形、关节位置、载荷质心、总质心及地面支点。保持力矩不足、支点无法平衡和零件强度不足是不同问题。没有做零件有限元分析的 link 会单独列出。一个姿态的静止结果不等于整个动作、工作空间或整机额定负载；电机质量等附属件可建成有真实惯量的固定子 link，载荷通过明确端口传递。

夹爪可以用 `analyze-gripper 任务.json --out 新目录` 一次整理并分析必检端点。例如传感器显示保持在15–17 N，声明误差±2 N，任务就要分别检查真实13 N和19 N；误差尚未实测时仍是待验证假设。有限软垫模型检查工件的力与力矩，仍不包含实际压强、柔度和摩擦标定。驱动力、驱动后座反力和指头强度也分别列出；刚性关节不会替你推断传动或安装。

需要看“抓取处移动多少”时，增加命名材料点或实际接触面的面积平均，再测两边相对位移。面积平均可以绕开接触面中心恰好是孔的情况；它不是孔中心的材料位移。测点仍要求收敛，并保留指尖等全局最大值。某项已明确失败、另一项未收敛时，报告会分别显示；不能用未完成项掩盖已确认失败。

预测只在输入条件、数值检查和相关判据都成立时提供，数值是本次声明模型的条件限制。无法确认时仍可观察假设模型的弹性反应，但不能把结果用于真实承重声明。持续使用、疲劳、冲击、温度、螺钉/墙体破坏和制造缺陷等未评估项会保留在报告中。

生成工具的迭代流程是：保持同一个任务编号和使用条件 → 生成新几何 → 重新检查尺寸/区域 → 分析 → 读取 `signal.json` → 用 `compare` 判断能否比较 → 根据瓶颈再生成。降低载荷、放宽允许变形或忽略失败工况不能冒充结构改进。无效或未收敛结果没有可用于奖励的有利分数。

需要更细网格时，用新的输入列表和新输出目录，加 `--reuse-levels 缓存目录`。符合严格匹配的已解网格保留，工具重新核对输入和求解场，只求解新增级别；原来的不确定结果不会被覆盖。采购件也可用 `interface-check` 对照明确图纸的尺寸/孔轴，保留厂家CAD、目录CAD和接口包络的来源差别。

产品交付前使用证据清单：材料与型号、实际装配、标定、控制、故障、寿命、实物验收分别记录。软件编译和状态测试属于“已有计算/软件检查”；实际测试登记后也可能是失败。旧记录绑定旧模型/夹具/代码的哈希，不会自动证明新版本。报告中的小型记录副本可在独立报告目录查看，不需服务整个工作目录。没有自己的模型时可从[短示例](../examples/quickstart/USE.md)了解输入、结果和覆盖边界。
