# 1.3 audit corrections and boundaries

| ID | Software requirement and observable verification |
|---|---|
| A01 | Campaign resume checks the recorded source-file hash map, not only numerical physics and output hashes. Changed task metadata/manifest requires a fresh immutable attempt. |
| A02 | A recorded contract contradicting the embedded case prevents comparison. Invalid/unresolved evidence clears public conditional capacity values. |
| A03 | Declared pose/component/independent-actuator and alternative-case coverage must be complete; a constituent failure cannot retain an aggregate usable pass. |
| A04 | Check actual output/cache volume free space, reserving256MiB plus a conservative node/element-based native-output or copy estimate. Failure retains partial evidence and actionable ENOSPC diagnostics. |
| A05 | Robot summaries link complete JSON and load geometry in a separate iframe. All unverified physical facts remain visible in the summary; read-only probe limits are explicit. |
| A06 | Robot task measurements explicitly state independent component fields and `whole_robot_displacement_available=false`. No propagation through the URDF chain is inferred. |
| A07 | Review all20 current source-bound cases, numerical gates, changed task definitions and physical/product scope; repeat current native tests without weakening criteria. |

The256MiB reserve and2048 bytes/node +8192 bytes/element per static/fixed/buckling job are conservative resource estimates, not solver output guarantees. Meshing, temporary native files, visualization or external filesystem changes may consume more. The toolkit never deletes or silently prunes evidence. Optional caches still require an explicit retention plan.

Contact/separation/friction/preload and elastic propagation through a robot chain require additional mechanical models and separately verified numerical references. This patch improves their disclosure and prevents evidence promotion; it does not implement these capabilities. A material-point numerical reference is not a physical fixture. Relative length is a first-order measurement, not a six-axis compliance model or a complete shaft-angle measurement.

Historical cross-drive source/report fixes are retained. Release validation may now write to a different volume and records an absolute path when a relative one is impossible. Numerical references, CAD interoperability and software tests do not qualify materials, assembly tolerances, hardware, finished products, external adoption or usability by independent novice users.

These are the1.3.1 audit boundaries. Version1.4 adds separately verified, opt-in [planar frictionless/applied-preload and first-order section-tree models](contact-and-transfer.md). Full frictional/bolt-pretension and coupled continuum/joint models remain unsupported; the original20-case records retain their original source/version and narrower task scopes.
